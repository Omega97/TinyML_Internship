# Table 5.1 — Base models and test cross-entropy

Base models and their test cross-entropy on the fixed 1.5M-position test set. It lists the dense baselines (Linear, single-hidden FFNN, dual-hidden FFNN2) and the five dual-POV two-hidden NNUE widths with their parameter counts. The reference model W128 H256 (174,723 parameters) attains CE 0.6303, beating the dual-hidden FFNN2 H256 at 2.9x the parameters — the NNUE inductive bias.
