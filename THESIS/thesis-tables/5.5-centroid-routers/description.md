# Table 5.5 — Parameter-free centroid routers

Parameter-free centroid routers (argmin cosine similarity to the k-means centroids), scored against the Euclidean Mini-Batch k-means labels on one million positions. The L1 router attains top-1 0.979 (B=2) to 0.940 (B=16), well above the board router (0.946 to 0.817), showing the L1 partition is nearly linearly recoverable.
